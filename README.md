# java-StudentCalculator

A console app written in pure Java that manages a class of students: enter grades, rank everyone on a leaderboard, see per-course stats, and find out which students are at risk and what to focus on.

Built with 1D arrays only 

Features :

- Add students (up to 50) with auto-generated IDs
- Enter or update grades for 4 courses: Programming, Math, Physics, English
- View a formatted table of all students with average and letter grade
- Leaderboard ranked by average (selection sort)
- Per-course stats: class average, top student, lowest student
- Search students by name (case-insensitive, partial match)
- At-risk report: students under 60 average, with their weakest subject
- One-click demo data so you can try everything instantly
